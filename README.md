# Haroe 10

הדמיה תלת-ממדית של הסלון והמטבח בדירה, לתכנון סידור הרהיטים: מצב נוכחי מול הצעה.

## הפעלה

לפתוח את `index.html` בדפדפן (דאבל-קליק). Three.js מקומי בתיקיית `vendor/` (r128), כך שאין צורך בשרת או באינטרנט, חוץ מהפונט.

## קבצים

- `index.html` — כל האפליקציה: הסצנה, הרהיטים, הפאנל
- `logo.svg` — הלוגו (משמש גם כ-favicon): קשת של פתח דלת, ובתוכה "10" — דלת בתור ה-1 ומראה עגולה מזהב בתור ה-0
- `icon.svg` → `icon-512.png`, `apple-touch-icon.png` — גרסת אייקון עם רקע מלא, למסך הבית בטלפון
- `manifest.webmanifest` — מאפשר "הוסף למסך הבית" כשהאתר מוגש מ-http(s)

## עריכת הסידור

כל רהיט מוגדר במערך `items` בקובץ `index.html`, עם מיקום לכל מצב: `[x, z, סיבוב, נראות]`.
החדר: x מ-0 (קיר הספה) עד 3.7 (קיר הטלוויזיה), z מ-0 (קיר הדלתות) עד 7.4 (קיר המטבח), במטרים.

## הסתייגות

המידות משוערות מתמונות — כ-3.7 × 7.4 מ׳, ספה כ-2.9 מ׳. מיקום המטבח בקצה החדר הוא הנחה.
